# Portfolio Website

This repository contains the source code for my personal portfolio website.  
The portfolio showcases my professional background, skills, projects, and ways to connect with me.

**Live Portfolio:**  
https://revansiddappa-c.vercel.app/

---

## Overview

The portfolio is designed to present a clean, modern, and responsive user experience.  
It highlights my work, provides direct access to my resume, and includes links to my professional profiles.

Key goals of this project:
- Create a professional online presence
- Showcase projects and technical skills
- Provide easy access to resume and contact links
- Ensure smooth performance and responsive design

---

## Features

- Fully responsive design for desktop and mobile
- Interactive UI with smooth animations
- Resume modal with view and download options
- Direct links to GitHub and LinkedIn profiles
- Clean and minimal visual design
- Deployed and hosted on Vercel

---

## Tech Stack

- **Frontend:** React, TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel

## Resume Access

The portfolio includes a resume section where users can:
- View the resume in a new browser tab
- Download the resume directly from a public Google Drive link

This functionality is implemented using standard anchor links to ensure compatibility across browsers and devices.

To run the project locally:

